记录使用Cursor做的事情

Posted on 2026-07-01 Word count in article: 813 Reading time ≈ 3 mins.

开发类

  1. 在项目文件夹下新建 specs/spec.md 文件，所有的长文本的需求可以放在 spec.md 中，让 cursor 去读取你的文件，根据你文件的要求去开发。同时也可以让 cursor 将开发的结果和结论放在 spec.md 中。
  2. 让 Cursor 去根据 spec.md 去构建镜像，告诉它镜像中需要哪些文件，基础的镜像是什么，然后它会自己去构建 requirements.txt。你可以要求它使用 Dockerfile，或者 docker-compose 去构建镜像，注意在使用 pip 下载 python 包的时候告诉它使用清华源镜像，不然会很慢。另外，注意配置 dockerignore,告诉它需要删除哪些不用的日志文件。
  3. 根据 debug 的结果，将 terminal 中运行的结果加入到 cursor 的输入的上下文中，并且告诉它运行的代码文件，问它为什么会出现这个问题，怎么解决这个问题。
  4. 在 cursor 的边栏输入框中，选中一些文件，让它基于你的需求去对选中文件去进行改造和 debug。cursor 能够访问的文件 不仅仅局限于选中的文件，还可以读取整个项目目录的文件，如果在它的 agent 判断需要读取其他的文件的情况下。

操作类

  1. 帮助清理磁盘空间，首先先找系统盘哪些文件可以删除，然后告诉它可以去删除哪些文件。在删除文件之前会找你去确认，一定要仔细查看它要删除的目录。
  2. 移动 docker 和 conda 包的存储位置，之前本来放在系统盘中，现在放在数据盘中。
  3. 帮助挂在硬盘。在云服务器上挂载了硬盘，但是在服务器的命令行中没有配置，那么可以告诉 cursor 你的数据盘的硬盘的大小，然后开始去做配置。
  4. 打开 cursor 的内置浏览器，打开并且登录你想要让 cursor 访问的网站，让 cursor 基于打开的网页去进行解读、总结和内容生成。

学习类

  1. 基础：给某个文件新增注释，给某个文件生成函数注释，解释某个函数的功能，让 cursor 去帮助你追踪某个函数的功能链路，让你知道在整个流程中，这个函数的作用。
  2. 进阶：生成项目的 readme.md，生成项目的流程图和架构图。

Cursor Agent

  1. 将需求放在项目根目录下的 specs/spec.md 中，打开 Agent window，让 cursor 基于 specs/spec.md 去开发。可以有多种要求（1）根据 specs/spec.md 去进行开发，（2）根据 specs/spec.md ，和我一起讨论我的任务的要求，并且跟我一起明确讨论需求中不明确的地方，然后开始讨论，（3）跟我 specs/spec.md 中的任务，和我一起讨论实现的方案，然后开始开发，最后将计划，以及任务的结果和部署方式放在 specs/spec.md 中。
  2. 让 Cursor Agent 去阅读你的项目，并且基于你的项目去进行改造，生成简历描述，生成技术 PPT，以及项目的架构、项目流程图。
