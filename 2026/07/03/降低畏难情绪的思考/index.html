降低畏难情绪的思考

Posted on 2026-07-03 Word count in article: 2.1k Reading time ≈ 8 mins.

今天在与同事聊 Agent 的时候，在聊完之后，我其实有想复盘，但是因为当时更想要去休息一下，去刷刷短视频来放松一下，也就暂时搁置。

主要聊到的是以下内容：

  1. 你的 Agent 使用的是什么架构？
  2. 在召回率低的时候，你会怎么做？系统性的思考和出发点。
  3. 有没有考虑过使用知识图谱来解决召回率低的问题？
  4. 有没有考虑过使用知识图谱，召回 node 之间的路径上对应的 chunk
    简单问题使用 react，难的问题使用 plan-and-execute，多步骤去解决。

在你使用 agent 的过程中出现了什么问题，你怎么去解决的。要模拟真实场景

  • 使用 AI 去帮助我生成几个 agent 在运行的时候会遇到什么问题，然后怎么解决的。我会去想好，问题的原因是什么？有哪些解决方案？为什么要选择当前的解决方案，你的考量是什么？
    多使用 AI 去帮助自己模拟真实的场景。

我发现有的时候畏难，主要是因为想要一下子将事情给做好。我以前想的复盘是，需要将我刚刚遇到的所有问题全部都记录下来，需要将我们对话的所有内容，方方面面都记录下来，这样才算是真正地复盘，否则遗漏任何一点对我来说都是灾难，还不如不记录。
后面我突然想到，如果我针对每次的对话，每次的面试都能够收获一点东西的，那么我使用题海战术去面试和与人交流，那这样我收获的内容就算不是 100%，如果能够得到大量实践之后的 80%的经验，那从最后的数量上来说我也是挣到了，于是我就不再纠结于全部，只要是每次都有一点收获，对过去的我来说都是一点金木，积少成多。
而且我接纳自己记不住所有的对话/学习内容，我接纳自己只能够吸收 70%的对话和学习的内容，但是也没有关系！我每次对话都能够学习到知识！
我就用概率的思想去学习和复盘。如果我这次复盘了，那收获的经验的概率值就是 0.7，如果我什么都不干，或者追求完美，后者的期望是 0.5 都不到，所以我还不如让自己放平心态，抱着能学一点就学一点的松弛的想法去学习和复盘，这样轻松的想法，不搞定所有一切的想法，不完美主义的想法，就能够让我前进的步伐轻盈很多。

最近我靠着这种想法做了很多事，比如我去配置了腾讯云服务器上的 Openclaw 的账号，能够对话。

刚开始我还是觉得麻烦，我心想为什么有的人能够通过配置 openclaw 给别人赚钱，我作为一个大模型应用算法工程师，我却做不到呢。能够做到对我来说就是一件完美的事，要么做成功，要么不做，这就是我的行事逻辑，我是很难接受我做事情只做一半的。所以我要么开始，痛苦地经历做事的过程，要么就躺平拖延啥都不干。
我是在意识到可以尝试去做一些简单的事情之后才开始行动。我在回想起来了之前在租这个腾讯云服务器的时候我是专门选择了一个 openclaw 的镜像的，就类似于那种非常简单的点点点，填写表单就可以部署的。
于是我就去网络上搜索腾讯云 openclaw 部署，看到腾讯云的官方教程文档，我跟着配置，发现，需要填写的内容很简单，只需要配置 API-KEY，以及选择接入的 IM 平台就可以了。我选择接入的平台是 QQ，接上之后就有一个腾讯 qq 的机器人，还有一个机器人专属的 qq 号，特别神奇。
我试着给这个机器人发送一个 hello 的消息，然后告诉我需要配置，没有配置争取的 API。于是我去网络上搜索这些报错是为什么，然后找到了一些博客园和 CSDN 的帖子，我就跟着打开了服务器的 linux 终端，我输入 openclaw configure 之后，发现出来一些配置分类给我选择，我选择配置 model API，然后通过多次点点点，发现在 more 里面有一个 Deepseek 的选项，然后我点击，发现需要我输入 API-KEY，然后我输入。告诉我配置成功之后，我又在 QQ 里面给 openclaw 发消息，发送 hello，成功了！我非常高兴，原来配置 openclaw 这件事对我来说没有那么困难！

靠着不一次性做完的想法，我还去给自己的 iPhone 配置了 VPN，我可以在手机上打开 VPN，然后去在手机上使用 ChatGPT 和 Gemini 等国外限制的大模型了。起初只是因为一个学妹告诉我，你可以在手机的 Chatgpt 上去让 AI 给你生图，在手机上生图可以有很多的选择。我当时非常想在手机上尝试一下，但是在手机上尝试，需要自己有 VPN。于是我就去找有 VPN 的方法。
我的 VPN 使用的是狗狗加速，我去看了一下它的官网发现有专门的 APP，看到 IOS 也有狗狗加速的 APP 之后，我很开心地去 App Store 上搜索狗狗加速，搜索了很多遍，上下划了好几次都没有发现这个 APP，去 APP 的安装教程发现，是需要通过美区账号登陆 app store 去下载的。
之前了解过 app store 的美区账号登陆，但是我因为觉得要花钱买很贵，我就没有购买，也没有了解后续的操作。这次我打算给自己一个尝试的体验，我想看看我能不能做到。
我知道我不会在国内的搜索引擎上找到苹果账号相关的网站的，于是我去谷歌搜索上搜索，然后马上就找到了。对比了两个苹果 id 的商店，我找了一个便宜的 12 块，支付之后，将账户密码以及一些验证信息放在 yuque 文档中，我在手机上跟着操作。
在最开始的时候，我是登陆上美区 id 账号的。我在 app store 上登陆，没有升级验证。我看我的 app store 上账号是美区，但是我去搜索发现还都是国内的 app。我很奇怪，然后我去看小红书上怎么登陆美区的 apple id，我看到了一个非常关键的信息，需要去设置-语言与时区里面设置为美国。
在我设置之后，我再次进入到 app store 我发现，成功切换到美国地区的 app store 了，我搜索 chatgpt，gemini 发现都搜索出来了。
好高兴。
但是我需要做的第一步还是，先去下载狗狗加速 app，然后打开 VPN，去使用 chatgpt。
下载狗狗加速 app，以及配置 VPN 对我来说比较顺利，就是跟着狗狗加速的官方教程去走就可以了。于是我非常成功地在手机屏幕向下滑的状态栏里面看到了 VPN 三个字母。

我知道我成功，这次的成功，原来很简单。似乎一切都很简单。
我没有抱着一定要尝试成功的想法，我就是想在手机上登陆 chatgpt，然后去做了一下简单的尝试，没有心理负担，就算是没有成功也没有关系，我就在电脑上使用就可以了。
没有想到，真的成功的，有的事情，很奇妙呢。我现在反思我之前有畏难情绪吗？感觉好像没有，很轻松。
