这周的感悟

去创造你想要的生活，而不是去适应你现在的环境。

去创造一种生活，而不是去适应一种生活。

最近一周我开始尝试新的生活，白天在公司认真上班，晚上回去只做休息一件事，我发现，我大部分时候早上能够正常起床，对下班之后要做的事情非常有动力，上班都比之前有劲了很多，因为我知道下班就是我的放松时刻。

所以在白天上班的时候，我有想法都会马上去实现，比如我有一个 vibe coding 的点子，我就会马上去实现，我觉得这对我来说很棒。

想学习一件事情，不要有前期的学习过程，直接开干，从干的过程中学习，不会的就去问 AI。干要通过 AI 去帮助自己去开发，让 AI 去讲述在这个过程中，会遇到的一些问题，以及新的概念/方法是怎么起作用的，我要看到我要学习的方法的效果长什么样子，以及怎么使用的。

一些提升行动力的小感悟：

  1. 在想要行动的时候，意识到可能会有阻碍/顾虑，马上行动不要停，马上行动能够带来正向反馈。
  2. 如果不想做一件事情，但是觉得自己需要去做，可以先从愿意行动的小事做起，比如不想洗衣服/出门，可以先去洗一双袜子，洗袜子是一件简单的事儿，当你洗袜子之后，你就已经行动起来了，行动起来之后，有了行动状态之后，身体/意识会想要继续去做下一件事，这个时候可以洗衣服/出门了。
  3. 将要做的事情，先乱七八糟地写在纸上，不需要去拆分步骤，就只记住自己要做的大目标，然后开始去行动就是了。发现最后一般能够做成。我尝试的事情是：使用 cursor agent 去阅读项目，将项目从 LLM 驱动变成从 harness 驱动，最后将项目的代码/步骤变成 Agent 岗位适配的简历描述。
  4. 先搞出来一个粗糙的，然后去修正自己的计划和行为，先开始再调整。没有完美的开始，只有开始和不开始。我尝试的事情是：写计划，先写出几个关键词，然后变成一句话，一个具体的目标。
  5. 不要过分拆解任务，比如刷牙，有的时候会懒，会想要拆分很多步骤去让自己行动起来，其实这样会加重大脑的认知负载，规定去刷牙，拿起来牙刷就去刷，不需要拆分到挤牙膏，拿出牙刷，刷上面，刷下面这种步骤。直接定任务，要刷牙，不要过分拆解，你先开始，你的行为习惯会带着你将刷牙这件事搞完。

  3. 使用 cursor agent，claude opus 4.8 去开发，现在 API 使用时 81%，用到位了。接下来想要好好使用 composer 去开发。想把钱都用到位。
